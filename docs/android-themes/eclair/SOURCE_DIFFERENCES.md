# Android 2.0 Eclair：来源与实现边界

基准：AOSP `android-2.0_r1`，提交 `92d82787e911d24b8b0ee24bb87c2922a595d9c4`。原始资源、字体、哈希与文件改动见 `import-spec.json` 和 `asset-manifest.json`。框架归档只取 `core/res/res`；字体取同一提交的 `data/fonts/DroidSans.ttf`、`DroidSans-Bold.ttf`，许可原文保存在 `FONT_NOTICE.txt`。

## 已实现的年代差异

- 页面使用 `Theme` / `Theme.Light` 的黑、白底和原始文字颜色选择器。字体为独立导入的 Droid Sans，未套用 ICS 的 Roboto。
- 标题条采用 `title_bar` 背景与14sp粗体白字，当前带可见菜单入口时保留48dp触控高度；标签采用 `tab_indicator`、64dp 基准高度、14sp 状态文字。菜单锚定在标题栏右端，未使用Action Bar或CAB。
- 按钮使用原始 `btn_default` 状态、9-patch 内边距和 14sp `primary_text_light`，深色主题也保留银色按钮与深色文字。设置开关呈现为 CheckBoxPreference，整行与控件的无障碍角色保持一致。
- 设置行沿用 `preference.xml` 的 64dp 最小高度、15dp 起始边距、22sp 标题和 14sp 摘要。列表选择器、复选框、单选按钮、分隔线和灰色分类标题均使用该版本资源。
- 目录选择采用经典浮动列表窗；AlertDialog 保留深色标题和消息区域、底部 medium 面板、左侧确认与右侧取消的原始顺序。进入和退出采用 150ms 缩放及透明度变化、二次减速曲线。开关窗口的通用状态机处理重入和取消，各年代分别提供动画参数。
- 搜索、刷新、全部排序及正反序通过可见菜单和经典输入框完成；多选时显示行内复选框及底部面板，包含数量、退出、全选、清除、设置语言。错误、重试、保存、权限与原有业务回调保持可达。

## Android 13+ 运行适配

- 无实体 Menu 键：标题条右端设置可见菜单入口，命令在锚定菜单中呈现。五个顶部标签在窄屏或大字号下可滚动。图标取同版 `ic_menu_*` 并按本应用目的地赋义，这些应用映射不声称是原系统五页导航。
- 操作目标至少 48dp，标题和描述允许按内容增高；未截断系统大字号以强行维持旧屏幕尺寸。
- 原始旋转资源的 `framesCount` / `frameDuration` 是当前 SDK 私有属性，不能直接链接。导入器将其转换为公开 `RotateDrawable`，保留原图和中心点，由 Compose 按原有 12 帧、每帧 100ms 驱动离散角度。原 XML 和转换参数均随清单保存，未改用现代圆形进度条。
- 状态栏与导航栏由当前系统提供，应用只设置黑色安全区和对比度，不绘制旧版时钟、电池或虚构系统按钮。现代模糊、玻璃效果暂停呈现，保存值仍保留。
- 区域标识中的系统 emoji、业务错误语义色、应用目录数据和配置功能属于本应用运行适配。它们不作为原版系统控件的像素复刻证据。

## 活跃标签与分页修订

原始TabWidget区分selected与focused：普通选中资源为银灰，焦点资源为橙黄。本应用按用户要求，把当前标签映射到旧TabHost常见的橙黄焦点样式，仍使用原始`tab_focus`资产。单击立即选择页面，双击由不消费事件的观察器识别，避免等待双击窗口后才执行单击。双击开关、键盘与无障碍回顶规则在各年代保持一致。

当前页面使用共享HorizontalPager仅移动正文，标题栏、经典标签和系统安全区固定；此适配用于Android 13+中的现代应用导航，并不声称Android 2.0自带该分页组件。
